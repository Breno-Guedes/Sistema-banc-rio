# 🏦 Sistema Bancário em C  

Este é um **sistema bancário simples**, desenvolvido em **linguagem C** para fins **didáticos**. O programa permite realizar operações bancárias básicas, como **consultar saldo**, **sacar** e **depositar dinheiro**, de forma prática e direta pelo **terminal**.  

---

## ⚙️ Funcionalidades  

- 💰 Consultar saldo  
- 📥 Fazer depósito  
- 💸 Realizar saque  

---

## 🧩 Detalhes Técnicos  

- Linguagem: **C**  
- Interface: **Terminal (CLI)**  
- As contas são **pré-definidas no código**, ideal para aprendizado de lógica de programação e manipulação de dados.  

---

## 🎯 Objetivo  

Projeto criado com fins **educacionais**, demonstrando o funcionamento básico de um sistema bancário, manipulação de variáveis, estruturas condicionais e funções em C.
